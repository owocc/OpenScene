OpenScene renders JSON scene documents in an application runtime and connects them to Studio for visual inspection.

## Reference modules

- [Studio bridge protocol](/en/protocol/) — the versioned iframe query and MessageChannel contract.

The protocol reference is generated from `packages/protocol/src/index.ts`, including exported TypeScript interfaces, types, functions, constants, and JSDoc comments.
